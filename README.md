# AIR Gate — Telegram Mini App для поиска авиабилетов и радара цен

Полноценное веб-приложение в формате **Telegram Mini App** для непрерывного мониторинга рынка авиабилетов, мгновенного поиска лучших предложений среди 40+ продавцов и создания умных подписок на изменение цен.

---

## 🚀 Ключевые возможности

1. **Агрегация всего рынка**:
   - Поиск по всем официальным авиакомпаниям, прямым лоукостерам и проверенным онлайн-кассам.
   - Сравнение продавцов в карточке рейса (прямой тариф авиакомпании vs онлайн-агентства).
   - Предупреждения о пересадках (короткие стыковки < 60 мин, ночные пересадки).
   - Индикатор тренда стоимости («Суперцена: на 26% ниже средней», «Высокий спрос: цена вырастет в течение 24ч»).

2. **Радар цен и Telegram-подписки**:
   - Настройка целевого порога цены в один клик прямо из результатов поиска.
   - Мониторинг гибких дат (±3 дня или весь месяц).
   - Мгновенные пуш-уведомления от Telegram-бота при падении цены ниже заданного лимита.
   - Вкладка «Радар цен» с симулятором реального пуша бота и историей экономии.

3. **Интеллектуальный поиск по соседним хабам**:
   - Поддержка альтернативных близлежащих аэропортов (например, при поиске из **Риги** предлагаются альтернативы из **Таллина**, **Вильнюса**, **Хельсинки** с экономией стоимости).
   - Поддержка мульти-аэропортов Москвы (SVO, VKO, DME).
   - Режим **«Куда угодно»** с подбором самых дешевых рейсов по всему миру.

4. **Физический жестовый интерфейс (Fluid Motion System)**:
   - Пружинная физика анимаций (Framer Motion) с плавным перенаправлением и прерыванием жестов.
   - Тактильная отдача Telegram Haptic Feedback (`impactOccurred`, `selectionChanged`, `notificationOccurred`).
   - Полупрозрачные матовые материалы (Frosted glass), адаптивная темная/светлая тема Telegram.
   - Интерактивный календарь низких цен с тепловой картой.
   - Быстрый шеринг билета в Telegram-чаты и каналы с карточкой предпросмотра.

---

## 🛠 Технологический стек

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS, Framer Motion, Lucide Icons.
- **Telegram Platform**: Telegram WebApp SDK (Haptics, ThemeParams, BackButton, MainButton, initData).
- **Backend**: Node.js, Express, Telegram Bot API, фоновый воркер сканирования цен.

## 📦 Быстрый старт

### 1. Запуск фронтенда (режим разработки)
```bash
npm install
npm run dev
```
Интерфейс откроется на `http://localhost:5173`.

### 2. Запуск Fullstack-сервера с бэкендом
```bash
npm run build
npm run server
```
Сервер запустится на `http://localhost:3001` (раздает и API, и Telegram Mini App).

---

## 🤖 Подключение Telegram-бота

1. Перейдите в Telegram к [@BotFather](https://t.me/BotFather).
2. Создайте бота (`/newbot`) и скопируйте токен в файл `.env`:
   ```env
   TELEGRAM_BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
   PORT=3001
   ```
3. Настройте Mini App в `@BotFather`:
   - Отправьте команду `/newapp`.
   - Выберите созданного бота, укажите название и загрузите аватар.
   - Укажите URL вашего приложения (например, адрес на ngrok, Vercel или собственном VPS).
   - Получите короткую ссылку вида `t.me/YourBot/app`.
